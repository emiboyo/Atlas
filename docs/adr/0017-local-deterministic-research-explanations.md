# ADR 0017: Local Deterministic Research Explanations

- Status: Accepted for private development
- Date: 2026-07-28

## Decision

Use a versioned local descriptive template with provenance and a configuration kill switch. Do not call an external AI service.

## Consequences

Explanations are reproducible, bounded, and cannot create transactions or events. Natural-language breadth is limited. External AI integration remains unauthorised.
